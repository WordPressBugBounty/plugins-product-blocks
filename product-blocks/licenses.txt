WowStore: third-party code and assets
=====================================

WowStore is licensed under the GNU General Public License v3 or later (see the plugin header). It includes the open source libraries listed below, all under licenses that are compatible with the GPL. Compiled JavaScript (assets/js/editor.blocks.js, assets/js/wopb_dashboard_min.js, addons/builder/assets/js/conditions.min.js)
---------------------------------------------------------------------------------------------------------------------------
The readable source of these bundles, and of everything else in the plugin, is public: https://bitbucket.org/wpstabon/product-blocks/src/master/ (folder reactjs/src).

React, ReactDOM, wp.element and Lodash are not bundled: these scripts use the copies WordPress registers (the `react`, `react-dom`, `wp-element` and `lodash` script handles).

Libraries bundled into them (name | version | license | source):

  string-convert | 0.2.1 | MIT | https://github.com/akiran/string-convert
